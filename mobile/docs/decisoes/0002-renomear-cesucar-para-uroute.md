# 0002 — Renomear CESUCAR para uRoute

**Data:** anterior a 26/08/2026 (registrada retroativamente)
**Quem decidiu:** grupo
**Status:** aceita

## Contexto

O produto nasceu como CESUCAR — trocadilho de CESUCA + CAR. Funcionou pra apresentação do semestre anterior. Mas o plano é replicar o modelo em outras universidades e, depois, em outros contextos empresariais.

## Alternativas consideradas

| Opção              | A favor                                                                                                              | Contra                                                                                                |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Manter CESUCAR** | Já reconhecido no semestre passado, trocadilho local funciona                                                        | Trava o projeto numa instituição só. Trocadilho só funciona escrito. Não cabe embaixo de ícone de app |
| **uRoute**         | De _University_ + _route_. Curto, pronúncia igual em português e inglês, cabe no ícone, não prende a marca ao CESUCA | Perde o reconhecimento local. Custo de retrabalho em material já feito                                |

## Decisão

O app mobile chama **uRoute**. O site legado segue como CESUCAR por enquanto.

## Por quê

Se a tese do projeto é replicar para outras universidades, uma marca que carrega o nome de uma instituição específica é um obstáculo desde o primeiro dia.

A identidade visual — azul, laranja, verde, o tom de voz — continua a mesma. O que muda é o nome e o logo.

## Consequências

- **Registro de marca vira urgente.** Trocar de nome duas vezes custa logo, domínio, ícone e apresentação. Antes de investir mais na marca, precisamos saber se "uRoute" está livre no INPI
- Material do semestre anterior precisa ser atualizado
- Em algum momento o site também migra, ou os dois nomes convivem com explicação
