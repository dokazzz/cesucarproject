Quero que você evolua o projeto Cesucar (sistema de caronas universitárias) mantendo o frontend em HTML, CSS e JavaScript e adicionando um backend em Python utilizando Flask.

OBJETIVO PRINCIPAL
Integrar Python ao projeto de forma funcional e profissional, atendendo aos requisitos acadêmicos, sem alterar a identidade visual atual do sistema.

FUNCIONALIDADES EM PYTHON

1. Criar uma API Flask organizada e estruturada.
2. Utilizar Programação Orientada a Objetos (POO).
3. Criar uma classe Carona responsável pelos cálculos e regras de negócio.
4. Criar uma rota GET /status retornando:

{
  "sistema": "Cesucar",
  "status": "Online"
}

5. Criar uma rota POST /calcular-carona que receba:

{
  "distancia": 25,
  "consumo": 12,
  "preco_combustivel": 6.00,
  "passageiros": 4
}

e retorne:

{
  "custo_total": 12.50,
  "valor_por_pessoa": 3.12
}

6. Criar um sistema simples de gerenciamento de caronas utilizando Python.

7. Preparar o projeto para futura integração com banco de dados.

8. Fornecer os arquivos:
   - app.py
   - carona.py
   - requirements.txt
   - documentação de instalação e execução.
